Library Design & Assembly

uSort-M is fully agnostic to input library composition. Any pooled DNA source can be used, including:

  • Commercial oligo pools (Twist, IDT)
  • Multiplex assembly products
  • Error-prone PCR libraries
  • Pooled site-directed mutagenesis
  • Degenerate codon libraries

Design Considerations

Library Size & Skew

The most critical factor affecting recovery efficiency is library skew—the fold-difference between the most and least abundant variants. Synthesis method determines both skew and the range of supported sequence lengths.

Method Length Max library size Skew (90/10) Delivery
Twist Oligo Pools 20–350 bp 54,000 <4× ssDNA pool
IDT oPools ≤350 bp — <4× ssDNA pool
Twist Multiplexed Gene Fragments 301–500 bp 696,000 ~2× dsDNA pool
Twist Gene Pools 300–1800 bp 696,000 ~1.5× dsDNA pool
Twist Cloned Oligo Pools 1–250 bp 696,000 ~3× Cloned in vector
Twist Cloned Multiplexed Gene Fragments (Early Access) 251–450 bp 12,000 ~2× Cloned in vector

Arrayed Gene Synthesis

For one-at-a-time synthesis of full-length genes (traditional approach, or when pooled options don't meet your length or diversity requirements):

  • Twist Gene Fragments — 300–5000 bp
  • IDT gBlocks — 125–3000 bp
  • IDT eBlocks — 300–1500 bp
💡 Tip: Use the usortm estimate command to predict required oversampling for your library parameters before ordering synthesis.

Sequence Length

Because uSort-M leverages long read sequencing for demultiplexing, it supports highly diverse library inputs. However, because the observed rate of synthesis errors scales with sequence length, libraries containing long sequences may require deeper oversampling to achieve full coverage.

Destination Vector

Parent vector that survives the assembly reaction transforms alongside the assembled products. Each parent-derived colony occupies a sorted well without contributing a library member, which lowers the coverage reached at a given fold-sampling. How that carryover is suppressed depends on the format the destination vector is supplied in.

Circular vector

Encode a ccdB cassette in the region excised by BsaI. Digestion removes the cassette from the assembled product; undigested and re-ligated parent retain it and kill the host, selecting against them without a separate purification step. The assembly transformation therefore needs a ccdB-sensitive strain, which includes NEB 5-alpha and other DH5α derivatives. Propagating the parent vector itself needs a ccdB-resistant strain such as DB3.1 (gyrA462).

Linearized vector

When the backbone is linearized by PCR from a circular template, the template is the carryover source. Amplify from a low input mass, on the order of 1 pg, using a high-efficiency, high-fidelity proofreading polymerase. The low input limits how much circular template reaches the assembly reaction, and the polymerase is what yields full-length backbone from that input while keeping the error rate low across the whole amplified vector. Digesting the PCR product with DpnI removes further template: plasmid prepared in a Dam-methylated host is cut, while the unmethylated amplicon is not.

Transformation Scale

The number of transformants should exceed your library size to ensure all variants are represented. We recommend:

  • 5–10× library size for uniform libraries (low skew)
  • 10–20× library size for skewed libraries

Planning Your Experiment

Cost Estimation

Before ordering synthesis, use the usortm estimate command to calculate projected costs and coverage for your specific library parameters: 

# Basic estimation for a 500-variant library
usortm estimate --library-size 500 --seq-length 300

# Custom oversampling and skew parameters
usortm estimate \
  --library-size 1000 \
  --seq-length 450 \
  --fold-sampling 6 \
  --skew 8

# Get JSON output for programmatic use
usortm estimate --library-size 500 --json

# Adjust FACS rates for your facility
usortm estimate \
  --library-size 500 \
  --machine-rate 85 \
  --operator-rate 70

The estimate command outputs:

  • Detailed cost breakdown by step (synthesis, cloning, sorting, barcoding, sequencing, hit-picking)
  • Comparison with traditional gene synthesis approaches
  • Effort metrics (time required for sorting and barcoding)
  • Expected timeline from start to finish

Experiment Planning

Create a complete experimental plan with the usortm plan command: 

# Create a project directory with experiment plan
usortm plan variants.csv --output my_experiment/ \
  --seq-length 300 \
  --fold-sampling 4 \
  --skew 4

# Plan with custom parameters
usortm plan variants.csv --output large_lib/ \
  --seq-length 500 \
  --fold-sampling 8 \
  --target-coverage 0.95

The plan command generates:

  • Project directory structure
  • Plate layout files
  • Reagent preparation lists
  • Predicted coverage statistics based on simulation
  • Timeline and checkpoint schedule

Transformation

  1. Thaw 25 µL NEB 5-alpha cells on ice.
  2. Add 3 µL Golden Gate reaction, mix gently.
  3. Incubate on ice, 30 min.
  4. Heat shock at 42 °C, 30 s.
  5. Return to ice, 5 min.
  6. Remove 1 µL for CFU determination (see Step 4).
  7. Add remaining cells to 1 mL LB + 100 µg/mL carbenicillin (LBcarb).
  8. Incubate overnight at 37 °C with shaking.

Determine Transformation Scale

  1. Dilute the 1 µL aliquot 1:20 and 1:100 in LB + antibiotic.
  2. Plate 20 µL of each dilution on LB-agar + antibiotic.
  3. Incubate overnight at 37 °C.
  4. Count colonies to estimate total transformants.
Target: Aim to transform >10× the number of unique sequences in your library size.

Prepare Glycerol Stock

  1. Mix 500 µL overnight culture with 500 µL sterile 50% glycerol.
  2. Store at −80 °C.
